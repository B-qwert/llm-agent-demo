## 使用方式

1. 复制 `.env.example` 为 `.env`，仅在本机填写 `LLM_API_KEY`，不得提交该文件。
2. 执行 `powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 init` 初始化环境变量。
3. 执行 `powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 up` 启动 Neo4j 和 Milvus。
4. 执行 `powershell -ExecutionPolicy Bypass -File scripts/dev.ps1 check` 重新执行全链路检查；报告会输出到本地 `reports/` 目录。

> 注：本报告记录的是上述时间点的真实验收结果。Docker Desktop 引擎需要处于运行状态，才能执行后续的在线复测。
