## 二、三种切法

| 切法 | 判定方式 | 块数 |
| --- | --- | --- |
| 按方法 | 认 `public/private/protected static ... (` 签名行，向下数花括号配对归零 | 12 |
| 按段落 | 遇空行断开 | 15 |
| 按定长 | 每 400 字符一刀，回退 80 字符重叠 | 42 |

## 三、向量化与入库

- 模型：`qwen3-embedding:0.6b`，本地 Ollama（`http://127.0.0.1:11434/api/embed`），输出 1024 维
- 库：Milvus `http://127.0.0.1:19530`，索引 AUTOINDEX + COSINE
- 集合：`code_chunks_v1`（方法切，正式）、`code_chunks_v1_paragraph`、`code_chunks_v1_fixed`（对照实验）

每条记录字段：`chunk_id`、`repository_id`、`snapshot_id`、`commit_sha`、`symbol_id`、`file_path`、`start_line`、`end_line`、`chunk_index`、`embedding_model`、`chunk_content_sha256`、`text`、`vector`。

标识算法：
- `symbol_id = "sym_" + SHA256([repository_id, language, entity_type, canonical_name])`
- `chunk_id = SHA256([snapshot_id, symbol_id, chunk_index, chunk_content_sha256])`
- 方法规范名形如 `experiment.bookBorrowSystem#borrowBook(java.util.Scanner)`，参数类型由 import 语句补成全限定名
